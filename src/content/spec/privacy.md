# 隐私与第三方服务说明

更新时间：2026 年 9 月 18 日

这是一份个人博客的服务说明。它用于解释本站页面、评论、统计和部分小组件会如何调用第三方服务；它不替代任何法律意见。本站会在相关功能发生变化时同步更新本页。

## 正常访问本站时

本站是以静态页面为主的个人博客，不要求访客注册本站账号，也不在本站保存 GitHub 登录密码、访问令牌、Cookie 或 Umami 管理密钥。文章阅读、搜索和页面导航本身不会要求访客填写个人资料。

浏览器与网站或外部服务建立连接时，网络服务通常会看到请求所需的 IP 地址、时间、User-Agent、请求路径和基本网络信息。这些信息由对应的网络服务商按照自己的隐私政策处理，本站无法替代服务商规定保存期限。

## 统计与性能数据

本站正式环境使用 Umami Cloud，当前开启：

- 页面访问统计；
- 外部链接点击事件；
- Web Vitals 浏览器性能指标。

当前未开启 Umami 会话回放，也未启用 Google Analytics、Microsoft Clarity 或 51.la。外部链接点击事件可能包含被点击链接的完整地址，因此链接地址中不应放入密码、令牌、手机号或其他敏感查询参数。

Umami Website ID 是前端脚本需要的公开站点标识，不是登录凭据。本站不会把 Umami 控制台密码、管理 Token 或 Cookie 写入页面。

## 评论与 GitHub 登录

文章、留言板以及其他开启评论的页面使用 Giscus，将评论存储在 GitHub Discussions。评论区按需加载，访客需要使用 GitHub 登录后才能发表评论。

评论内容会按照 GitHub 仓库和 Discussions 的公开规则展示。GitHub 登录发生在 GitHub/Giscus 提供的页面中，本站不接收或保存 GitHub 密码、个人访问令牌和登录 Cookie。不要在评论中填写身份证号、住址、手机号、账号密码或其他不希望公开的信息。

Giscus 的仓库、分类和 ID 是公开配置标识，不等同于 GitHub 管理权限。评论功能受 GitHub、Giscus、网络环境和浏览器扩展影响；评论暂时不可用时，文章正文仍可阅读。

## 第三方小组件

部分页面会按功能和屏幕宽度请求第三方资源，常见情况包括：

- 音乐组件请求音乐、封面或歌词接口；
- 每日一言组件请求当天的句子接口；
- 首页宽屏侧栏的 GitHub 贡献热力图请求公开数据接口；
- 追番等页面可能请求 Bilibili 或其他公开内容接口。

这些请求由访客浏览器直接或间接发起，可能向对应服务发送请求时间、IP、User-Agent、公开账号标识和请求内容。本站不向这些接口发送登录 Cookie、本站评论凭据或 Umami 管理密钥。第三方接口不可用时，相关小组件会显示降级状态，不应阻塞文章主体。

## 动态与 Memos

本站当前动态使用构建时生成的本地 `/api/dynamic.json` 数据。真实 Memos 数据源保持关闭，因此当前不会连接 Memos 实例，也不会在浏览器中暴露 Memos 访问令牌。

如果以后启用 Memos，将先单独更新本页，说明实例、数据范围、跨域设置和回滚方式，再进行线上验收。

## 公开账号标识

本站可能展示博客作者主动提供的 GitHub、Bilibili、网易云音乐、QQ 或邮箱入口，以及 Umami、Giscus 所需的公开标识。它们用于跳转公开主页或连接公开服务，不是密码或管理密钥。

如果你不希望使用这些外部功能，请不要点击对应入口；也不要把自己的私人信息写入评论、外部链接查询参数或公开动态。

## 联系与更新

如需反馈隐私相关问题，可通过[关于页](/about/)中的公开联系方式联系。本站会在统计、评论、动态或第三方接口发生实质变化时更新本页的更新时间和对应说明。
