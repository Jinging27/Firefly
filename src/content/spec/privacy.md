# 隐私与第三方服务说明

更新时间：2026 年 9 月 18 日

## 先看结论

这是一个以静态页面为主的个人博客。本站不要求访客注册账号，阅读文章、搜索和页面导航也不要求填写个人资料。

- 评论使用 Giscus，评论内容公开保存在 GitHub Discussions，发表评论需要先登录 GitHub；
- Umami 当前只开启页面访问统计、外部链接点击和 Web Vitals（页面加载与性能指标）；
- Umami 会话回放、Google Analytics、Microsoft Clarity、51.la 和真实 Memos 数据源当前关闭；
- 音乐、每日一言、GitHub 贡献热力图等小组件按页面需要请求对应的外部服务；这些服务不可用时，不应阻塞文章正文。

## 当前功能状态

| 功能 | 状态 | 用途 | 访客需要知道 |
| --- | --- | --- | --- |
| Umami Cloud | 已开启 | 页面访问、外链点击、Web Vitals | 外链点击事件可能包含目标 URL |
| Umami 会话回放 | 已关闭 | 记录操作过程 | 本站当前不录制会话 |
| Google Analytics、Microsoft Clarity、51.la | 已关闭 | 访问或行为分析 | 本站当前不加载这些统计服务 |
| Giscus | 已开启 | 文章、留言和动态评论 | 需要 GitHub 登录，评论公开显示 |
| Memos | 已关闭 | 实时动态数据源 | 当前动态来自本站构建的本地 JSON |

这份说明解释本站当前的实现边界，不替代 GitHub、Giscus、Umami Cloud 或其他第三方服务自己的隐私政策和数据保存规则。

## 本站、浏览器和第三方分别会接触什么

### 本站本身

本站不提供账号注册，也不在博客中保存 GitHub 登录密码、访问令牌、登录 Cookie 或 Umami 管理密钥。博客源码和构建产物中不会写入这些凭据。

浏览器与本站或外部服务建立连接时，对应的网络服务通常会看到请求所需的 IP 地址、时间、User-Agent、请求路径和其他基础网络信息。本站无法替第三方服务承诺保存期限或处理方式。

### 浏览器本地存储

为了记住访客自己的显示选择，本站可能在当前浏览器的 `localStorage` 中保存主题、壁纸、音量、文章列表布局和其他界面偏好。这些偏好不会因为保存到浏览器而自动上传到本站；清除本站的浏览器数据后，相关设置会恢复默认值。

如果访问加密文章或相册，输入的密码只在浏览器当前会话的 `sessionStorage` 中缓存，并在本地用于解密内容，不会作为评论或统计数据提交给本站。不要把重要账号密码复用于此类文章密码。

### 第三方服务

第三方请求由访客浏览器直接或间接发起，可能按对应服务商的政策处理网络和设备信息。本站不会把本站的评论凭据、Umami 管理密钥或其他后台凭据发送给这些服务。

## 统计与性能数据

本站正式环境使用 Umami Cloud，当前开启：

- 页面访问统计；
- 外部链接点击事件；
- Web Vitals 浏览器性能指标。

外部链接点击事件可能包含被点击链接的完整地址，因此链接地址中不应放入密码、令牌、手机号或其他敏感查询参数。Umami Website ID 是前端脚本需要的公开站点标识，不是登录凭据。

当前未开启 Umami 会话回放，也未启用 Google Analytics、Microsoft Clarity 或 51.la。以后如果打开这些功能，应先更新本页，再进行线上验收。

## 评论与 GitHub 登录

文章、留言板和当前开启评论的动态页面使用 Giscus，将评论映射到 GitHub Discussions。访客需要在 GitHub 完成登录，本站不会接收或保存 GitHub 密码、个人访问令牌和登录 Cookie。

评论内容、评论时间和 GitHub 公开账号信息会按 GitHub Discussions 的公开规则显示。要修改或删除自己的评论，应在对应的 GitHub Discussions 中操作；不要在评论里填写身份证号、住址、手机号、账号密码或其他不希望公开的信息。

Giscus 的仓库、分类和 ID 是连接公开 Discussions 所需的公开配置标识，不等同于 GitHub 管理权限。评论暂时不可用时，文章正文仍可阅读。

## 音乐、每日一言和其他小组件

部分页面会按功能和屏幕宽度请求第三方资源，常见情况包括：

- 音乐组件请求歌曲、封面或歌词接口；
- 每日一言组件请求当天的句子接口；
- 首页宽屏侧栏的 GitHub 贡献热力图请求公开数据接口；
- 追番等页面可能请求 Bilibili 或其他公开内容接口。

这些请求可能向对应服务发送请求时间、IP、User-Agent、公开账号标识和请求内容。本站不向这些接口发送登录 Cookie 或管理密钥。第三方接口不可用时，相关小组件会显示降级状态，不应阻塞文章主体。

## 动态与 Memos

当前动态使用构建时生成的本地 `/api/dynamic.json` 数据。真实 Memos 数据源保持关闭，因此访客打开动态页面时，浏览器不会连接 Memos 实例，也不会接触 Memos 访问令牌。

如果以后启用 Memos，将先单独更新本页，说明实例、数据范围、跨域设置和回滚方式，再进行线上验收。

## 访客可以怎么做

- 不要把敏感信息写入公开评论、动态或外链查询参数；
- 不需要某个外部小组件时，可以不点击或使用浏览器的脚本/内容拦截功能，但这可能让评论、音乐或统计功能不可用；
- 如需修改或删除 GitHub 评论，请在 GitHub Discussions 中操作；
- 如需反馈隐私问题，可通过[关于页](/about/)中的公开联系方式联系。

本站可能展示作者主动提供的 GitHub、Bilibili、网易云音乐、QQ 或邮箱入口，以及 Umami、Giscus 所需的公开标识。它们用于跳转公开主页或连接公开服务，不是密码或管理密钥。

## 联系与更新

当统计、评论、动态或第三方接口发生实质变化时，本站会更新本页的更新时间和对应说明。第三方服务的实际保存期限、网络可达性和处理方式以其自身政策为准；本页不构成正式法律合规意见。
